TESTING 테스트

As ISTQB Foundation Level Certified Tester I review my code in two phases. Firstly, I write a code and finish it from a developer's perspective. After this I review my code from a tester's perspective with a purpose to find any bugs in my code and fix them before submitting my work. Having two perspectives keeps my code as clean as possible. Additionally, I also have acquired A4Q Selenium Tester Foundation certification for creating automation tests. I hold experience in writing front-end E2E tests by using Playwright. ISTQB Foundation Level Certified 테스터로서 저는 두 단계에 걸쳐 코드를 확인합니다. 우선, 코드를 개발자의 관점에서 작성합니다. 그 이후 테스터의 관점에서 코드를 확인하여 버그를 수정하곤 합니다. 두 가지 관점을 가지고 업무를 진행하면 코드를 가능한 한 깨끗하게 유지할 수 있습니다. 또는 자동화 테스팅 을 하기 위해 A4Q Selenium Tester Foundation 자격증을 받았습니다.
